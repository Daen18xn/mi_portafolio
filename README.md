## 📄 Descripción del Proyecto
Este proyecto es un portafolio web personal e individual diseñado para presentar los avances académicos y trabajos prácticos del semestre en la asignatura de Desarrollo de Frontend.

---

## 🎯 Audiencia y Propósito
* **Audiencia objetivo:** El docente evaluador del curso y la comunidad académica.
* **Necesidad identificada:** Mostrar de forma ordenada, jerárquica y accesible las evidencias de aprendizaje del bloque RA1, incluyendo el ejercicio práctico de Flexbox/Grid y la maquetación responsiva.

---

## 🛠️ Trabajos Incluidos
1. **Ejercicio Guiado (Sesión 5):** Maquetación con Flexbox para centrado de tarjetas y CSS Grid para una estructura de 3×3.
2. **Portafolio Web (P2):** Interfaz completa en HTML5 semántico con diseño adaptativo.

---

## 📐 Decisiones de Diseño y Accesibilidad
1. **Estructura Semántica:** Uso de `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` y `<footer>` sin el uso innecesario de `<div>`.
2. **Diseño Responsivo (3 Breakpoints):**
   * **Móvil (`< 600px`):** Vista vertical en columna para una lectura fluida.
   * **Tablet (`601px - 1024px`):** Ajuste de dimensiones, márgenes y botones.
   * **Escritorio (`> 1025px`):** Alineación horizontal en la cabecera y tarjetas de trabajo lado a lado.
3. **Accesibilidad (WCAG/WAI-ARIA):**
   * **Contraste:** Fondo claro (`#f4f4f9`) con texto de alto contraste (`#222222`) y azul institucional (`#1b365d`).
   * **Formularios:** Uso de etiquetas `<label>` vinculadas a sus campos `<input>` mediante atributos `for`.
   * **Navegación:** Enlaces con foco navegable por teclado.
